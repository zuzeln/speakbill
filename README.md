# 随口记 (Speakbill) 用户隐私政策与技术支持

> 更新日期：2026年9月22日 · 生效日期：2026年9月22日

随口记（Speakbill）是一款专为 iOS 原生打造的极速记账与日常备忘工具。我们始终致力于保护您的个人隐私与资产数据安全。

---

## 一、权限调用与数据收集原则

我们遵循极简与最小必要原则，仅在您主动触发相应功能时申请系统权限：

1. **麦克风权限（NSMicrophoneUsageDescription）**：仅在您主动按住主界面语音悬浮按钮进行口述记账时调用。音频数据直接在设备本地实时进行语音转写，我们不会在任何远端服务器上留存或录制您的原始语音音频。
2. **语音识别权限（NSSpeechRecognitionUsageDescription）**：用于调用苹果 iOS 系统原生的高精度端侧语音识别引擎，将您的口述转换成结构化记账文本。
3. **面容 ID / 触控 ID（NSFaceIDUsageDescription）**：仅在您开启“生物识别解锁”隐私防窥功能后，调用苹果系统安全隔离区（Secure Enclave）验证身份。应用本身不接触、不收集、不存储您的任何面容或指纹生物数据。
4. **相册访问权限**：仅在您主动使用“AI 识图记账”从相册挑选发票、小票或支付账单截图时调用，应用仅读取您单次主动选中的图片。
5. **相机权限**：仅在您点击“拍摄纸质小票”时调用，用于即时取景拍摄发票小票，拍摄后图片在端侧进行文字提取。

---

## 二、财务数据的本地存储与 iCloud 私有同步

- **纯本地存储优先**：您的核心记账明细、账户余额、资产卡片和多账本数据全部保存在您设备的本地沙盒数据库中。
- **私有云同步安全**：若开启同步，数据仅通过您个人 Apple ID 绑定的苹果官方私有云存储（iCloud CloudKit）进行端到端加密传输与存储，开发者不设立独立用户数据库，无法查看、归集或转售您的任何账单数据。
- **数据导出自主权**：本应用支持将账单导出为 CSV 标准表格文件。导出文件由 iOS 系统原生分享面板直接送达您指定的位置（如本地文件或隔空投送），不经由任何第三方中间服务器。

---

## 三、AI 智能解析服务特别说明

当您使用 AI 口述拆单或截图识图功能时，转写文本或小票图片会通过行业标准高强度加密传输协议（HTTPS）发送至大模型解析服务以提取商户、金额及分类。传输过程中不附加任何能识别您真实个人身份的信息，解析完成后即时丢弃，绝不用于模型重新训练或商业画像。

## 四、未成年人保护

本应用主要面向具备完全民事行为能力的成年人。若您为未成年人，请在法定监护人的陪同与指导下阅读并使用本应用。

### 常见问题解答
1. **换新手机后，之前的记账数据会丢失吗？**  
   不会。随口记原生支持苹果 iCloud 私有同步。只要新手机登录相同的 Apple ID，安装应用打开后即可秒级自动同步历史记账明细与资产卡片。
2. **手机处于离线断网或飞行模式时，可以口述记账吗？**  
   可以。应用内置了端侧原生离线分词引擎与本地轻量规则解析，无网络状态下依然可以毫秒级提取金额、分类并完成快速记账。
3. **财务数据会不会被上传到开发者私有服务器？**  
   绝对不会。随口记贯彻端到端隐私保护原则，全部数据存放于 iOS 本地沙盒及您个人受密码保护的 iCloud 容器中。
4. **如何导出我的记账账单数据？**  
   在主界面或设置页面中，点击“数据导出”按钮，即可一键生成标准的通用 CSV 表格文件。
